## Calendar toggle on a Date picker

`provideNativeHijriDateAdapter()` is for a plain `mat-datepicker` that stores a `Date`. The ready-made fields stay on `CalendarDate`.

The only gap on the native path is a calendar toggle on that plain datepicker. The toggle would change the text on screen only, because a `Date` has no calendar to store. It does not need new fields.

Build it later only if people ask for it.
