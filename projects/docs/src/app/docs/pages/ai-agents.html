AI agents

The published package includes a skill at agents/SKILL.md. It is plain markdown. Any coding agent that can read a file in the project can follow it.

AGENTS.md

After ng add, the file is node_modules/ngx-mat-hijri-adapter/agents/SKILL.md. Copy it to AGENTS.md at the project root. Agents that follow that convention read it, in whatever editor you use.

If the project already has an AGENTS.md, add this skill to that file. Copying replaces the whole file:

A skills folder

Some agents load SKILL.md from a folder of their own and use the name and description at the top of the file. Copy the same file there. The folder is the one that agent documents, for example .agents/skills/ngx-mat-hijri-adapter/SKILL.md, .claude/skills/ngx-mat-hijri-adapter/SKILL.md, or .cursor/skills/ngx-mat-hijri-adapter/SKILL.md.
