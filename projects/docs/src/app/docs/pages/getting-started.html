Getting started

Add a Hijri or Gregorian datepicker to an Angular Material app in three steps.

Install

Version {{ version }} is tagged on GitHub and not yet published to npm. Once it is, install it with its peer dependency:

Angular core, forms, material, and cdk are peer dependencies too, and are expected to be in the app already.

Requirements

  • Angular core, forms, material, and cdk 22.0.0 or newer. Signal forms are stable from this version; Angular 21 is not supported.
  • @internationalized/date 3.12.0 or newer. CalendarDate is part of the public value type, so it is a peer dependency.

Register the adapter

Register the adapter once in the application providers. The defaults are the Umm al-Qura calendar and the ar-SA locale.
