Hijri and Gregorian dates for Angular Material

One date adapter for the Umm al-Qura and Gregorian calendars, with ready-made fields for reactive and signal forms. Built on @internationalized/date.

Angular 22 · Material 3 · Signal forms

Why this package

Built for both calendars from day one

The name says Hijri, but every part handles the Gregorian calendar too. Values are CalendarDate objects, never a JavaScript Date, so no time zone shifts a day.
